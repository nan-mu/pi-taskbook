# Resolve the members' findings

Address every finding by ID. When it exposes a real omission, false pass or fact conflict, change the relevant plan passage and state what was changed. When the evidence rebuts it, cite the decisive passage, observation or prior user decision. A response must enable the members to verify the result independently.

When several examples expose the same gap, revise the acceptance rule so it covers the whole class. For an inventory, specify how the source reveals new items or branches of the same kind. Cite the revised rule in each finding's resolution and keep representative examples that show how to apply it.

Choose `confirm` with the resulting candidate and one resolution per finding. Use `how`, `why` or `consult` to answer a specific evidentiary question. Ask the user to decide a protected fact or scope question through `needs-user`.
