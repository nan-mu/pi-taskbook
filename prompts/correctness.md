# 规格审核

启动新的独立审核会话。在 T3 Code 中使用可用的原生委派能力。给审核者任务书、相关事实、固定基线、待审提交、实际变更和已有证据。审核者只读检查，独立判断任务书要求的行为、原有调用方的兼容性、异常或边界情形和验收证据。

逐项核对交付判据。能够重跑的必要检查择关键项独立复核。指出具体缺的行为、证据或验收覆盖，并附文件位置、命令、结果或可追溯产物。仅涉及正式性能测量的判据，留待性能阶段验证。任务书要求独立意见且无法启动该审核时，报告阻塞及缺失能力。

阶段报告提供独立审核的子 thread 标识。存在导致无法交付的规格问题时提交阻塞。通过时记录已验收的判据和仍需实际测量的判据。
